To compile and run the code, open the current directory in the command line and type:
    `./node.exe main`
    The program will read in any file named "hamlet.txt" in the current directory and output the encoding into "output.txt".
There is already an "output.txt" provided which contains a successful encoding of "hamlet.txt"

Feel free to run the testing suites using
    `./node.exe testDictionary` and
    `./node.exe testHTree`
