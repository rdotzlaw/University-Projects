Code by Ryan Dotzlaw

To run the code
type `make` in command line once inside the src folder
then type `A2 <filename>` to read in from a file placed inside the src folder
- A2-official-data.txt is already in src folder

To test the code:
type `make test` once inside the src folder

NOTES:
- There is a bug where some events execute later than they should and because it was inconsistent, I was unable to find it's cause in the time given. This bug causes some of the wait times to be larger than they should be.
- I am unaware of any other bugs.
